# Experiment 21 — JDBC CRUD

1. Install MySQL and start the server.
2. Create the database: `CREATE DATABASE java_practicals;`
3. Replace `YOUR_MYSQL_PASSWORD` in `Main.java`.
4. Add MySQL Connector/J to your IDE/project classpath.
5. Run `Main`.

The example demonstrates CREATE TABLE, INSERT, SELECT and UPDATE. A DELETE example is included as a comment so the sample row remains available. Never commit real database credentials.

## Aim
To demonstrate jdbc crud with statement and preparedstatement.
